## Engineering Principles

- Code is a tool for solving problems; the frontend/backend boundary should not limit the solution.
- Understand the real problem before choosing the technical approach.
- Clear boundaries matter more than complicated abstractions.
- Refactoring and migration should support continuous product delivery.
- Automate repeated work and reserve time for decisions that require judgment.
- Technology can change quickly; systems should remain understandable, verifiable, and maintainable.
- Ship, observe, and improve.

I enjoy challenging projects, especially problems that are complex, unfamiliar, heavily constrained, and still expected to produce a real result.
